runtime-dmc-pi

A single-user service that runs on owner-controlled hardware and connects a dedicated agent Google account to explicitly configured personal workflows.

01

Purpose

runtime-dmc-pi helps its owner review information and carry out limited owner-directed tasks from a privately operated agent account. It is not offered as a public application or multi-user service.

  • Read messages in the dedicated agent mailbox when requested or when an owner-configured workflow requires them.
  • Draft email and send only after explicit owner approval or under a narrowly defined scheduled policy.
  • Read calendars that the owner explicitly shares with the agent account when calendar workflows are enabled.

02

Access boundaries

Account-specific
Google authorization applies only to the agent account that grants consent. It does not grant access to the owner's other Google accounts.
Read-only inbox access
Mailbox reading does not delete, modify, label, archive, or mark messages as read.
Human control
External actions remain subject to explicit approval or a preconfigured policy with recipient and frequency limits.

03

How data is handled

  1. Authorize: The owner grants narrowly scoped Google OAuth access to the dedicated agent account.
  2. Process: Requested data is processed on owner-controlled hardware and, when necessary, by configured AI services.
  3. Review: Results are returned through private owner-controlled channels. Outbound actions follow approval rules.
  4. Revoke: The owner can revoke Google access and remove locally stored authorization at any time.

Details are available in the Privacy Policy.
