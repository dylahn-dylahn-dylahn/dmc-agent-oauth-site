# dmc-agent-oauth-site

Public OAuth application information for `runtime-dmc-pi`, a private single-user personal agent service.

## Public boundary

This repository contains only the static OAuth homepage, privacy policy, terms, and presentation assets. It must not contain credentials, OAuth tokens, email addresses, private message or calendar content, infrastructure identifiers, internal service configuration, or operational logs.

## GitHub Pages

Publish from the repository's `main` branch and root directory. Expected paths:

- `/` - application overview
- `/privacy.html` - privacy policy
- `/terms.html` - terms of use

The site uses plain HTML and CSS with no JavaScript, analytics, cookies, forms, or third-party runtime assets.
